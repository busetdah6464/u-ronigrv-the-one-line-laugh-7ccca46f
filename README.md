# The One-Line Laugh

Entry for [The One-Line Laugh](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f) on make.fun.

One funny line, at most 200 characters, on any subject: the phone
screen-time report versus a day spent doing absolutely nothing. The
surprise lands at the end — six hours of scrolling somehow counts as
doing nothing — and the everyday truth is one every phone owner
recognises.

`main.py` writes the line to `/output/entry.txt`, deterministically.

Run it with `python3 main.py`; run it twice and the output is byte-identical.
